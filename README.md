# محمد يبحث — مختبر القراءة الدكتورالية

تطبيق شخصي لإدارة القراءة الأكاديمية وتوليف الأدبيات، يعمل على كل الأجهزة (الحاسوب، الآيباد، الجوال) ويُزامن المحتوى نفسه بينها.

**الرابط بعد النشر:** https://assoulim.github.io/research/

---

## البنية

| الطبقة | التقنية | الدور |
|---|---|---|
| الواجهة | `index.html` على GitHub Pages | التطبيق كاملاً في ملف واحد، ويُثبَّت كتطبيق (PWA) |
| التخزين المحلي | IndexedDB | نسخة كاملة على كل جهاز، فيعمل التطبيق دون إنترنت |
| المزامنة | Supabase (Postgres، منطقة لندن) | صف لكل مقال، مع قواعد أمان تحصر البيانات في حسابك |
| Claude | Supabase Edge Function | مفتاح API محفوظ على الخادم ولا يصل إلى المتصفح |

**آلية المزامنة:**
- كل تعديل يُحفظ محلياً فوراً، ثم يُرفع بعد ثانية ونصف.
- التحديث من الأجهزة الأخرى عند فتح التطبيق، وعند العودة إليه، وكل دقيقة أثناء الاستخدام.
- التعديلات غير المرفوعة على الجهاز تتقدّم على النسخة البعيدة.
- الحذف ينتقل إلى كل الأجهزة.

---

## الإعداد (مرة واحدة)

### 1. قاعدة البيانات
Supabase ← **SQL Editor** ← New query ← الصق محتوى [`supabase/schema.sql`](supabase/schema.sql) ← **Run**.

### 2. روابط تسجيل الدخول
Supabase ← **Authentication ← URL Configuration**:
- **Site URL:** `https://assoulim.github.io/research/`
- **Redirect URLs:** أضف `https://assoulim.github.io/research/`

### 3. دالة Claude
Supabase ← **Edge Functions** ← Deploy a new function ← **Via Editor**:
- الاسم: `claude`
- الصق محتوى [`supabase/functions/claude/index.ts`](supabase/functions/claude/index.ts) ← Deploy.

ثم **Edge Functions ← Secrets**، وأضف:

| الاسم | القيمة |
|---|---|
| `ANTHROPIC_API_KEY` | مفتاحك من console.anthropic.com (يُفضّل بحدّ إنفاق شهري) |
| `ALLOWED_EMAILS` | بريدك الإلكتروني (للفصل بين أكثر من بريد استخدم الفاصلة) |
| `CLAUDE_MODEL` | اختياري، مثل `claude-sonnet-5-5` |

### 4. صفحات GitHub
المستودع ← **Settings ← Pages** ← Source: *Deploy from a branch* ← Branch: `main` / `(root)` ← Save.

### 5. حسابك
1. افتح الرابط واختر **«أول مرة؟ أنشئ حسابك»**.
2. أكّد بريدك من الرسالة التي تصلك، ثم سجّل الدخول.
3. **أغلق التسجيل بعدها:** Supabase ← Authentication ← Sign In / Providers ← عطّل *Allow new users to sign up*.

### 6. التثبيت على الأجهزة
- **آيباد / آيفون:** افتح الرابط في Safari ← زر المشاركة ← **Add to Home Screen**.
- **ماك / ويندوز:** في Chrome أو Edge ← أيقونة التثبيت في شريط العنوان.

## نقل بياناتك من النسخة القديمة (ملف واحد)
1. في النسخة القديمة: الإعدادات ← **تصدير نسخة احتياطية (.json)**.
2. في التطبيق الجديد بعد تسجيل الدخول: الإعدادات ← **استيراد نسخة احتياطية**.
3. تُرفع المكتبة تلقائياً وتظهر على بقية أجهزتك.

---

## الأمان
- `config.js` يحوي مفتاح **anon** العام فقط، وهو مصمَّم ليكون علنياً. قواعد RLS في `schema.sql` تمنع أي حساب من رؤية بيانات غيره.
- **لا تضع أبداً** مفتاح `service_role` أو `secret` في المستودع.
- دالة Claude ترفض أي حساب غير مدرج في `ALLOWED_EMAILS`.
- المستودع العام يحوي الكود فقط، أما بياناتك البحثية ففي قاعدة البيانات وحدها.

## التطوير المحلي
```bash
python3 -m http.server 8000   # ثم افتح http://localhost:8000
```
إذا كان `config.js` فارغاً، يعمل التطبيق في وضع محلي على جهاز واحد دون تسجيل دخول.
